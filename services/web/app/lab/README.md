## 격리 방식 (이 폴더 밖을 건드리지 않는 장치)

1. **토큰 오버라이드** — `globals.css`의 CSS 변수를 래퍼 `style`에서만 다크 값으로 덮는다. 안쪽의 `bg-surface`·`text-brand` 같은 시맨틱 클래스가 전부 랩 팔레트로 풀리고, 전역 테마 토글과 무관하게 항상 다크다.
2. **오버레이** — `fixed inset-0`으로 화면 전체를 덮어 루트 layout의 Navbar(라이트 기준 기존 디자인)와 섞이지 않게 한다.

## 조절 패널 (`/lab` 우측 하단)

6축 슬라이더로 실시간 조정하고, 하단 수치 문자열을 그대로 알려주면 [theme.ts](theme.ts)의 `DEFAULTS`에 고정한다.

| 축 | 조절 대상 |
|---|---|
| `TERMINAL` | 터미널 어휘량 — 상태바 → 페인 테두리 → 제목 인셋·`❯` 커서 → `//`·`>` 프롬프트·대시 리더 순으로 켜짐 |
| `DENSITY` | 여백 배율 0.65~1.5 |
| `CONTRAST` | 배경/본문 명도 차 |
| `WARMTH` | 뉴트럴 웜 바이어스 (0=중성 회색, 100=Gruvbox 계열) |
| `ACCENT` | 앰버 노출량 |
| `PIXEL` | 비트맵 서체 범위 (없음 → 라벨·숫자만 → 전체) |

**현재 확정값**: `terminal=65 density=0 contrast=70 warmth=100 accent=0 pixel=55`
**로그인 상태 토글**도 여기 있다 — 개인 스트립이 붙은 홈과 공개 홈을 번갈아 본다.

## 본 서비스 적용 시 할 일

1. 조절 패널·`theme.ts`의 노브 계산 제거 → 확정 값을 `globals.css` 다크 팔레트로 이관
2. `fixed inset-0` 오버레이 해제, 루트 Navbar를 랩 네비 디자인으로 교체
3. 정적 더미 데이터를 `entities/*/api` 실데이터로 교체
4. ⚠️ **다크 기본 전환은 [ADR-0002](../../../../docs/decisions/0002-poc-scope-and-design.md)의 "라이트 기본"(2026-07-11 사용자 결정)을 뒤집으므로 새 ADR을 발행**한다
