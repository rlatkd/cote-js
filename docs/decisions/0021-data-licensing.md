# 0021. 문제 데이터 라이선스 — 게시는 100% 자체 생산, 외부 데이터는 내부 용도 한정

- **상태**: Accepted
- **일자**: 2026-08-01

## 맥락 (Context)

M3(AI 문제 생성) 착수의 선결 과제로 "데이터 라이선스 문제"가 초기부터 최우선 리스크로 기록돼 있었다(엔지니어링 노트, ADR-0001). 논의 과정에서 이 문제가 단일 문제가 아니라 **용도 3가지로 갈리고 각각 법적 노출이 다르다**는 것이 정리됐다:

1. **게시(재배포)** — 문제를 서비스에 올려 사용자에게 보여주는 것. 백준·프로그래머스·LeetCode 지문은 저작물이고 ToS도 수집·재게시를 금지한다. 포트폴리오는 저장소·서비스 공개가 전제라 노출이 가장 크다.
2. **LLM 생성 참고(few-shot·스타일 기준)** — 내부 이용, 재배포 아님. 리스크 낮으나 생성물이 원본의 파생물이 될 위험이 있고, 그 방어선이 M4 유사도 검사 + 사람 검수 게이트다.
3. **M4 유사도 코퍼스(임베딩)** — 내부 분석·비표시. 리스크 낮음. "기존 유명 문제와 유사한가"를 재는 대조군.

추가로 실측된 사실: 현재 dev 시드 5문제(1000·2231·1932·7576·9019)는 실제 백준 ID·제목·제약을 그대로 쓴 파생물이다(지문은 요약이지만 동일성 명백). 저장소가 공개인 시점에 시드 SQL 자체가 이미 재배포에 해당한다.

## 결정 (Decision)

1. **게시 문제 = 100% 자체 생산.** 서비스에 게시되는 문제는 M3 생성물(검수 게이트 통과) + 초기 수작성 소수만. 외부 문제는 게시 경로(problem 테이블 → api → web)에 절대 들어가지 않는다.
2. **외부 공개 데이터셋은 내부 용도 2가지에 한정** — ① LLM 생성 참고(few-shot) ② M4 유사도 코퍼스(임베딩). **채택 시점에 개별 라이선스 실확인**을 조건으로 한다(후보: Project Euler=CC BY-NC-SA로 알려짐, ICPC 계열 문제셋 일부=CC BY-SA, HF 데이터셋=내부 이용까지만).
3. **현행 백준 파생 시드 5문제는 M3에서 검수 통과한 생성 문제로 교체**한다(부채, TODO 추적).

## 근거 (Rationale)

- **문제 적합성**: 이 프로젝트의 정체성이 "AI 문제 생성"이므로 **외부 문제를 재배포할 필요가 애초에 없다.** 라이선스 문제를 정면 돌파(라이선스 확보)하는 게 아니라 구조적으로 우회하는 선택지가 존재하고, 그게 제품 방향과 일치한다.
- **포트폴리오 가치**: 공개 저장소·공개 서비스에서 저작권 리스크는 감점 요인이고, 반대로 라이선스 정책을 ADR로 남기는 것 자체가 법적 리스크 인식을 보여주는 가점 요인이다.
- 정답 검증은 외부 데이터와 무관하게 자기 완결적이다(지문→N개 독립 풀이→실채점→합의 — 엔지니어링 노트 '생성 문제 정답 신뢰성'). 외부 데이터가 없어서 검증이 약해지는 구조가 아니다.

## 검토한 대안 (Alternatives)

- **(A) 기존 사이트 크롤링(백준·프로그래머스·LeetCode)** — 배제. ToS 위반 + 저작권 침해. 공개 포트폴리오에서 최악의 신호.
- **(B) 공개 데이터셋 전면 채택(게시까지)** — 배제. CodeContests·TACO·APPS 등 HF 계열은 데이터셋 자체의 라이선스 표기와 무관하게 **원천이 타 사이트 스크랩이라 '라이선스 세탁' 위험** — 게시(재배포)의 법적 근거가 되지 못한다. 내부 이용까지만 허용.

## 결과 (Consequences)

- 게시 문제의 공급이 전적으로 M3 파이프라인(+수작성)에 걸린다 → M3의 품질 게이트(교차검증·사람 검수)가 서비스 품질 그 자체가 된다.
- 시드 교체 전까지 저장소의 백준 파생 시드는 임시 상태로 남는다(버려질 픽스처 전제 유지, M3에서 상환).
- 외부 데이터셋 채택 시마다 라이선스 실확인 절차가 붙는다(자동 신뢰 금지).
- **뒤집히는 조건**: ① 상업 서비스화 → NC(비상업) 라이선스 셋 제외, 자체 코퍼스 중심 재설계 ② M4 유사도 검증이 외부 유명 문제 대비를 지금 가정보다 높은 수준으로 요구하면 코퍼스 확보 전략 재검토.
